# Оновлення CryptoBot v0.3.4 → v0.3.5

Версія 0.3.5 додає до Telegram-повідомлень пояснення фактичного рішення:

- чому діє денний PAPER-захист;
- скільки торгових пар перевірено;
- які рішення отримані для пар;
- яких умов сигналу не вистачило;
- що має статися для повторної перевірки або входу.

Стратегія, PAPER-угоди, SHADOW-угоди та обмеження ризику не змінюються.
Можливість реальних ордерів залишається вимкненою.

## Безпечне оновлення у Windows

1. У вікні старого бота натисніть `Ctrl+C` і підтвердьте завершення, якщо
   PowerShell запитає.
2. Розпакуйте архів у нову окрему папку.
3. Скопіюйте папку `data` зі старої версії 0.3.4 у корінь нової версії 0.3.5.
4. Скопіюйте локальний `.env` зі старої версії 0.3.4 у корінь нової версії.
   Не надсилайте й не публікуйте цей файл: у ньому міститься Telegram-токен.
5. У PowerShell перейдіть у папку нової версії та виконайте по черзі:

   ```powershell
   npm.cmd ci
   npm.cmd test
   npm.cmd run build
   npm.cmd start
   ```

6. На старті перевірте значення:

   ```text
   mode=paper
   live-capability=false
   telegram=all
   ```

Не запускайте версії 0.3.4 і 0.3.5 одночасно: вони використовують той самий
порт і не повинні паралельно змінювати копії торгового стану.

## Очікуваний новий блок Telegram

```text
Чому бот прийняв це рішення:
• Денний PAPER-захист: ...
• Проскановано пар: 10
• пробій закритою свічкою не підтверджено: BTC/USD, ETH/USD, ...
• BTC/USD, ETH/USD, ...: Жодна остання закрита свічка 1M, 5M або 15M не закрилася вище свого рівня опору
Що потрібно далі: дочекатися закриття свічки 1M, 5M або 15M вище максимуму попередніх 20 закритих свічок
```
