# Самодосконалення paper-бота

Увімкнено за замовчуванням: SELF_IMPROVEMENT_ENABLED=true. Працює лише в paper-режимі. Модуль змінює тільки множник часу утримання (0.75, 1 або 1.25); остаточні межі 3–30 хвилин. Він не переписує код, не змінює сигнал Фібоначчі, стоп, ціль, ліміти ризику або перевірку новин. Це обмежений адаптивний підбір параметра, не нейромережа.

Після підтвердженого сигналу зберігається віртуальний експеримент; для однієї пари не частіше ніж раз на 30 хвилин. На наступних скануваннях бот бере 30 повних закритих 1M-свічок після сигналу та порівнює результати трьох часових варіантів. При пропусках даних експеримент відкидається. Комісії і налаштоване прослизання враховано. Якщо свічка одночасно торкається стопа та цілі, береться стоп. Це наближений OHLC replay, а не підтверджений результат реального виконання.

Для першого рішення потрібні 50 повних спостережень: 30 для вибору кандидата, наступні 20 для перевірки. Кандидат повинен мати позитивний середній результат у двох вибірках і перевершити активний варіант на перевірці мінімум на 0.1R. Інакше параметр залишається незмінним. Наступний перегляд — після ще 50 спостережень. За новими даними можливе повернення до базового множника. Без достатніх даних діє множник 1.

Файл data/learning-state.json містить поточний множник, незавершені експерименти, результати та історію рішень. Він створюється після першого сканування й зберігається атомарно. Старі paper/shadow угоди не видаються за навчальну вибірку: потрібних цінових траєкторій у них немає. Не видаляйте data/. Запускайте один екземпляр бота на цю папку.

Бот не відкриває додаткових угод заради навчання. Модуль працює під час звичайних сканувань; якщо сканування зупинено лімітом 200 угод або захистом, накопичення також може зупинитися. Уже відкриті позиції не отримують нових дедлайнів при зміні множника. Вимкнення модуля не видаляє пам’ять.

Запуск після оновлення: npm ci; npm run build; npm test; npm start. Збережіть свій поточний .env і data при розпакуванні. У .env можна явно додати SELF_IMPROVEMENT_ENABLED=true. На /health поле selfImprovementEnabled показує, чи модуль увімкнено; це не означає, що він уже накопичив дані або змінив параметри.

Перевірки: збірка та 198 автоматичних тестів успішні. Перевірено поріг вибірки, відхилення перенавчання та збиткових кандидатів, витрати, пріоритет стопа, перезапуск без дублювання даних і відмову при пошкодженій пам’яті. Прибутковість на нових ринкових даних ще не підтверджена.
